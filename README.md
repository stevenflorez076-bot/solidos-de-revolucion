## Uso

Abre `index.html` con conexión a internet. Discos, Arandelas y Cascarones tienen páginas propias con los datos, el desarrollo de la integral, un diagrama 2D y un modelo 3D de GeoGebra. El control de sección mueve la marca en los dos diagramas. El control de divisiones recalcula la aproximación por puntos medios.

El [informe PDF](Informe.pdf) contiene la presentación del trabajo. Sus enlaces originales siguen abriendo cada ejercicio. La carpeta [comandos](comandos) contiene las instrucciones de GeoGebra para reproducir las construcciones.
